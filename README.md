# CreativeFlow build files

The files GitHub needs to build the CreativeFlow iPhone and Mac apps: the app page (the same one served at https://app.creativeflow.media), the desktop app shell and icons, and the build workflows.

This repository is updated automatically from the main (private) CreativeFlow project. Please don't open pull requests here.

Signing certificates and keys are stored in this repository's GitHub secrets, not in its files.
